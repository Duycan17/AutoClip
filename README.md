# AutoClip

Ứng dụng cắt video dài thành clip ngắn, chạy cục bộ trên Windows và macOS.

## Tải về

Tải bộ cài mới nhất tại [GitHub Releases](https://github.com/Duycan17/AutoClip/releases/latest).

| Hệ điều hành | Tệp cần chọn |
| --- | --- |
| Windows 10/11 64-bit | `AutoClip-Portable-...-x64.exe` (chạy ngay) hoặc `AutoClip-Setup-...-x64.exe` (cài đặt) |
| macOS Apple Silicon (M1/M2/M3/M4) | `AutoClip-...-mac-arm64.dmg` |
| macOS Intel | `AutoClip-...-mac-x64.dmg` |

Yêu cầu: Windows 10/11 64-bit hoặc macOS 64-bit. Bản Windows 32-bit không được hỗ trợ.

## Bắt đầu

1. Tải và mở bộ cài.
2. Đăng nhập bằng tài khoản do quản trị viên cấp.
3. Kéo thả video hoặc dán link YouTube, chọn thời lượng rồi tạo clip.

## YouTube yêu cầu xác minh

Nếu YouTube báo cần xác minh trên mạng của bạn:

1. Trong tab **Link YouTube**, dán link và nhấn **Mở YouTube để xác minh**.
2. Hoàn tất xác minh hoặc đăng nhập YouTube trong trình duyệt trên cùng máy và mạng.
3. Chọn đúng trình duyệt ở **Dùng phiên trình duyệt** rồi thử lại.

Nếu vẫn lỗi, hãy đổi mạng (ví dụ hotspot điện thoại) hoặc tải video bằng trình duyệt rồi dùng chức năng **tải tệp lên**. YouTube quyết định IP nào được phép tải.

## Lưu ý

- Bộ cài chưa ký số; Windows SmartScreen hoặc macOS Gatekeeper có thể cảnh báo trong lần mở đầu tiên.
- Repo này chỉ chứa bộ cài phát hành; mã nguồn không được công khai.
- Phiên đăng nhập desktop do quản trị viên quản lý và có thể bị thu hồi.
